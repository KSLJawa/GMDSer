# 范围界定与版本锚点

本文面向系统／经济策划作品集，关注《三角洲行动》烽火地带的经济系统。核心问题是：**收益、损失与交易约束，如何共同影响不同资产水平玩家的持续入场与风险选择？**

## 一、研究边界

| 项目 | 本文口径 |
|---|---|
| 研究版本 | 保留原稿的 S10 赛季作为历史锚点，不将本次编辑日期视为实测日期 |
| 区服 | 以国服原稿观察为主要对象；国际服资料单独标注，不直接替代国服规则 |
| 平台 | 原稿未逐项记录平台，待原图补齐；不同平台的界面与支付档位不自动合并 |
| 实测时间 | 原稿未附完整日期与原始截图，涉及数值、状态和使用限制的记录保留为“原稿观察，待补证” |
| 本次修订 | 2026-11-15，修订概念、论证和计算，不代表重新进入游戏实测 |
| 覆盖内容 | 哈夫币与物资循环、交易约束、风险收益、资产分层，以及与外观经济的连接 |
| 外围系统 | 全面战场等模式的奖励只作为外部输入标注；不展开其完整经济循环 |

战斗与关卡仅在影响经济决策时进入讨论，例如战备价格、存活率、路线风险、背包容量和撤离机会。不以本文证明开发历史、后台真实架构或运营团队的唯一设计动机。

## 二、四种论述身份

| 标记   | 含义                             | 允许得出的结论                |
| ---- | ------------------------------ | ---------------------- |
| 官方资料 | 可定位的开发者／发行方公告，注明日期、区服和适用版本     | 仅支持其明确披露的规则            |
| 原稿观察 | 作者或素材提供者的游戏观察；本轮未附原图的项目明确标注待补证 | 描述观察记录，不把单个样本推广为全局规律   |
| 分析推断 | 对现象的解释，包括设计收益、成本和副作用           | 给出理由、其他可能解释与验证方法       |
| 分析模型 | 为核算、比较或复现机制而建立的个人模型            | 说明假设与适用边界，不冒充官方配置或线上数据 |

例如，“挂单价格存在区间”是可截图核验的界面规则；“限价可能降低异常定向转移的空间”是分析推断；“用物品覆写表实现限价”是个人复现模型。这三层不能互相充当证据。

## 三、统一计量口径

- **个人资产**：一个账号的现金、可用物资与权益。区分可支配现金、物资变现价值和不可逆养成进度。
- **全服货币存量**：本分析边界内所有账号持有的同一种货币，包含已冻结、待领取等仍归玩家所有的余额。它们的转移与领取不重复计为增发。
- **物资存量**：按物品种类、数量和必要状态记录。局内／局外是位置，玩家间转移是归属变化。
- **估值**：分析时选择的折算价格。价格上涨引起的账面增值与新增物品、现金收入分别记录。
- **风险收益**：以单局前后的净资产变化核算，计入装备损失、消耗品、费用与实际保留收益。

本文不假定玩家资产始终增加，也不把现金存量视为所有玩家的唯一进度条。

## 四、如何读图与截图

流程图表达系统关系，分析图表达假设及计算；**它们不能替代游戏界面的证据截图**。截图应靠近其证明的规则，标明来源、拍摄日期、版本、操作前后状态及可支持的结论。

已附分析图与待补游戏截图分别登记于 [[13-证据索引与截图清单]]。缺图位置使用文字 callout，不放伪造界面，也不把后续版本截图标为 S10 实测。

## 五、当前结论的限度

本轮能够核对的是账本分类、模型内部逻辑与概率运算；不能由此证明真实用户分布、全服通胀状态、后台补货行为或实际留存提升。涉及这些问题时，正文给出验证方案与待收集数据。
